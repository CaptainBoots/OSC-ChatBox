# VRChat ToolBox Instructions & Conventions

This file contains development standards and conventions established for the VRChat-ToolBox codebase. All developers and agents must abide by these rules.

---

## Versioning Convention

Whenever you modify or update any companion tool or the parent ToolBox application, you MUST increment its version string following the `Major.Minor.Patch` format:
* You are authorized to autonomously increment the **Minor** or **Patch** versions as needed for feature additions and bug fixes.
* You MUST request explicit permission from the user before incrementing the **Major** version.
